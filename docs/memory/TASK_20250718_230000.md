## 🚨 Decisión Estratégica Crítica - Empaquetado con AppImage

### 📋 Problema Identificado
PyQt6 requiere dependencias del sistema (`libxcb-cursor0`) que los usuarios finales tendrían que instalar manualmente con `sudo apt install`, complicando la distribución y rompiendo la promesa de "cero configuración".

### 💡 Consulta con Experto Externo
**Consultor recomendó:** Mantener PyQt6 + empaquetado con AppImage para resolver distribución sin sacrificar diseño moderno.

### ✅ Decisión Aprobada por Líder
**Estrategia seleccionada:** PyQt6 + PyInstaller + AppImage

### 🎯 Justificación Técnica
1. **Mantiene diseño aprobado** - Interfaz PyQt6 moderna ya validada
2. **Portabilidad total** - AppImage funciona en cualquier distribución Linux
3. **Cero dependencias** - Todo empaquetado en archivo único ejecutable
4. **Desarrollo fluido** - No requiere reescribir código existente
5. **Distribución simple** - Un archivo, un clic, funciona

### 🛠️ Plan de Implementación
1. **PyInstaller** - Empaquetar Python + PyQt6 + dependencias
2. **AppImage** - Convertir en ejecutable universal
3. **Build automatizado** - Script para generar versiones
4. **Testing** - Verificar en múltiples distribuciones

### 📦 Resultado Esperado
- **Usuario descarga:** `spotlight-linux.AppImage` (archivo único)
- **Usuario ejecuta:** Doble clic o `./spotlight-linux.AppImage`
- **Cero configuración requerida**
