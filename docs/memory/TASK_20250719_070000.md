# 🎯 Sistema de Preferencias para Spotlight Linux

## 📋 Objetivo
Crear un sistema de preferencias accesible mediante un icono que permita a los usuarios configurar:
- **Nombre de usuario** - Cómo quieren que la IA se dirija a ellos
- **Tono de IA** - Estilo de comunicación (formal, casual, técnico, amigable)
- **API Key de Gemini** - Credenciales para el motor de IA

## 🎨 Diseño de la Interfaz

### Icono de Preferencias
- **Ubicación**: Esquina superior derecha de la ventana principal
- **Icono**: ⚙️ (gear/engranaje)
- **Comportamiento**: Click abre ventana de preferencias

### Ventana de Preferencias
```
┌─────────────────────────────────────┐
│ ⚙️ Preferencias - Spotlight Linux   │
├─────────────────────────────────────┤
│                                     │
│ 👤 Información Personal             │
│ ┌─────────────────────────────────┐ │
│ │ Nombre: [Eduardo            ] │ │
│ └─────────────────────────────────┘ │
│                                     │
│ 🤖 Configuración de IA              │
│ ┌─────────────────────────────────┐ │
│ │ Tono: [Amigable ▼]            │ │
│ └─────────────────────────────────┘ │
│                                     │
│ 🔑 API Key de Gemini                │
│ ┌─────────────────────────────────┐ │
│ │ API Key: [••••••••••••••••••] │ │
│ └─────────────────────────────────┘ │
│                                     │
│     [Guardar]  [Cancelar]          │
└─────────────────────────────────────┘
```

## 🔧 Implementación Técnica

### Archivos a Crear/Modificar
1. **`preferences.py`** - Ventana de preferencias
2. **`config.py`** - Gestión de configuración
3. **`main.py`** - Agregar icono de preferencias

### Configuración de Almacenamiento
- **Ubicación**: `~/.config/spotlight-linux/config.json`
- **Formato**: JSON encriptado para API key
- **Estructura**:
```json
{
  "user": {
    "name": "Eduardo",
    "tone": "amigable"
  },
  "ai": {
    "api_key_encrypted": "...",
    "model": "gemini-2.5-flash-lite-preview-06-17"
  },
  "ui": {
    "theme": "dark",
    "language": "es"
  }
}
```

### Opciones de Tono de IA
- **Amigable**: Conversacional y cercano
- **Profesional**: Formal y directo
- **Técnico**: Preciso y detallado
- **Casual**: Relajado e informal
- **Entusiasta**: Energético y motivador

## 🔒 Seguridad
- API key almacenada con encriptación básica
- Archivo de configuración con permisos 600
- No mostrar API key completa en UI (solo últimos 4 caracteres)

## 🎯 Flujo de Usuario
1. Usuario abre Spotlight Linux
2. Si no hay configuración → mostrar wizard de primera vez
3. Usuario puede acceder a preferencias via icono ⚙️
4. Cambios se aplican inmediatamente
5. Configuración persiste entre sesiones
